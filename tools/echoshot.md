# EchoShot

多镜头同角色人像视频生成（西安交大 + 阿里云，arXiv 2506.15838）。基于 **Wan2.1-T2V-1.3B**：按提示词一次生成多条**同一个人物**的镜头，内容可控——解决多镜头叙事里的换脸问题。

## 干什么用

短片里同一主角跨镜头保持同一张脸。真题：`urban-romance` 三镜（进门的对视、越界的毛巾、对坐与对视）都是 Lin 和 Lu——独立抽卡时三张脸对不上，EchoShot 就是这条路上的轮子。
