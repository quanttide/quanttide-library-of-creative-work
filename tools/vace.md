# VACE

视频创作与编辑一体框架（通义，ICCV 2025）。官方定位 all-in-one，三类任务可自由组合：**R2V**（参考图出视频）、**V2V**（整条视频改风格）、**MV2V**（遮罩局部改——圈出一块改一块），官方举的例子有 Move-Anything、Swap-Anything、Reference-Anything、Expand-Anything、Animate-Anything。官方直接提供 **VACE-1.3B** 权重与 ComfyUI 集成。

## 干什么用

真题两条：一是把 `1_2_越界的毛巾.png` 定稿图当条件，长出 `videos/1_毛巾.md` 那条 9:16 一镜到底——正是 journal「视频只需生成图片和图片之间的关系」的工具版；二是生成分镜哪里不对，MV2V 圈出来只改那块。

## 与图生视频（I2V）的区别

本质一句话：**I2V 是「给一张起始图，让画面动起来」；VACE 是「把图、视频、Mask、姿态/深度等条件一起喂进去，指定哪里保留、哪里重画、怎么动」**。VACE 包含 I2V 这个子模式，但能力边界远大于它——反过来理解也成立：装好 VACE 后只填 `src_video` 的第一帧、不填 mask 不填参考图，跑出来就是标准 I2V 效果，I2V 只是它最“平淡”的一种用法。

**输入与控制维度不同**。普通 I2V（Wan2.1-I2V）：一张起始图 + 提示词（部分工作流加 CLIP Vision 做图像特征对齐），只决定「第一帧长什么样」和「后续怎么动」，中间和结尾靠模型发挥——想让画面某个具体位置按指定方式变化、保住角色长相、只改背景不动主体，基本靠抽卡。VACE 官方抽象成 4 个可选输入字段，用哪个字段就对应哪种任务：

| 字段 | 作用 |
|------|------|
| `prompt` | 文本描述（必填） |
| `src_ref_images` | 参考图，指定主体/背景长相 |
| `src_video` | 源视频或控制信号（深度图、姿态、光流、线稿、灰度） |
| `src_mask` | 3D 遮罩，白色区域重画、黑色区域保留 |

关键在 `src_mask` 这个概念解耦机制——模型明确知道「哪些像素该动、哪些不能碰」，这是普通 I2V 根本做不到的。

**能力覆盖**：首尾帧补间（I2V 需 FLF2V 专用模型）、参考图保持角色一致性、姿态/深度/光流控制、局部替换/移除/重绘（需 Inpainting 专用模型）、画面外扩、能力自由组合——普通 I2V 全部做不到，VACE 分别对应 FLF2V / R2V / V2V / MV2V 模式；且官方 VACE-Benchmark 上单项任务（I2V、inpainting、outpainting、depth、pose、光流）也优于其他开源专用方案——不是“什么都会但都不精”，而是统一之后还更强。

**代价**：预处理绕不开（姿态控制先跑姿态提取、局部重绘先画 Mask、参考生成要准备参考图并做主体分割；官方有 VACE-Annotators 与 Gradio 预处理界面，但比 I2V「丢一张图写句话」的门槛上一档）；性能上 1.3B 生成 5 秒 480P 在 A100 约 310 秒、显存约 28GB（官方示例，随任务浮动）；社区实测里 R2V 任务上 1.3B 与顶尖商业模型仍有差距，14B 才是主力。

**怎么选**：只要“静态图动起来”→ 直接用 Wan2.1-I2V，简单快；要保角色、换物体、控动作、扩画面中的任何一个 → 上 VACE；视频后期（换主体、改背景、去物体、转风格）→ 只有 VACE 能干。

## 1.3B 为什么能打

参数量不等于能力上限。纯 T2V 模式下只有一句提示词可以控制，天花板确实明显；VACE 把控制方式打开了——参考图、源视频、Mask、姿态/深度等结构信号可分别指定“要保留什么、要重绘什么”（概念解耦），1.3B 的容量更多用在“怎么把任务执行好”，而不是“猜你想干嘛”。对比：纯 T2V 让角色做指定动作要写一堆提示词、抽卡、大概率翻车；VACE 给一张角色图 + 一段姿态骨架视频直接出、成功率高得多——不是模型变强，是给它的信息变明确了。

反直觉经验：**1.3B + 好的条件输入，经常比 14B + 纯提示词效果更可控**。参数量主要影响画质上限、运动流畅度、细节丰富度；可控性这件事上，给对条件比堆参数更重要。具体创作任务反而是 1.3B 更趁手——跑得快、迭代成本低、效果够稳。

## 玩法清单

投入产出比高的场景：

- **角色一致性视频**：一张角色立绘 + 一句提示词 → 该角色在不同场景、不同动作下的视频（短视频账号、虚拟人设）
- **图生动效**：静态插画、老照片、商品图转短视频（电商主图、社媒素材）
- **局部替换（Swap Anything）**：原视频 + Mask + 参考图，换掉视频里某个物体，不用重拍不用绿幕
- **视频风格迁移**：真人转动漫/油画/皮克斯风，一张风格参考图
- **画面扩展（Expand Anything）**：竖版扩横版、画面加宽加高，AI 自动补全
- **首尾帧控制**：给第一帧和最后一帧，AI 补全中间过渡，做转场

压榨 1.3B 的四招：

- **多条件组合**：参考图 + 姿态 + Mask 三件套一起上，先小范围测组合；条件不是随便叠加就更好，可能互相打架，需控制强度、分步加条件或调权重
- **ControlNet 式预处理**：VACE-Annotators 提取深度图、线稿、光流再喂进去，控制力上一个台阶
- **社区加速 LoRA**：蒸馏 LoRA 能把推理步数从 50 步压到 8-10 步，出片速度起飞
- **多片段拼接**：1.3B 生成 81 帧很快，多段生成再剪比一次憋长视频稳定得多
