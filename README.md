# 量潮创意工作图书馆

QuantTide Library of Creative Work

视频生成轮子（Wan2.1-T2V-1.3B 生态）的介绍与出处查证，为 `examples/quanttide-create-lab` 的实验选型提供参考。

## 目录

| 目录 | 工具 | 用途 |
|------|------|------|
| `tools/echoshot.md` | EchoShot | 多镜头同角色人像视频生成 |
| `tools/phantom.md` | Phantom | 参考图定角色的主体一致性视频生成 |
| `tools/vace.md` | VACE | 参考图控视频与视频编辑一体 |
| `tools/flowedit-flowalign.md` | FlowEdit / FlowAlign（WANAlign2.1） | 免训练改视频 |
